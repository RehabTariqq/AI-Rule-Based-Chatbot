# Reva - Rule-Based AI Chatbot 🤖

Reva is a simple rule-based AI chatbot developed as part of an Artificial Intelligence internship project.

The chatbot uses predefined rules, conditional statements, and a continuous conversation loop to simulate basic human-computer interaction.

## Features

- Greeting responses
- Basic conversation
- Answers simple questions
- Help command
- Unknown-input handling
- Multiple exit commands
- Continuous conversation loop

## Technology

- C++

## Concepts Used

- Variables
- Strings
- User input
- `if`
- `else if`
- `else`
- `while` loop
- `break`
- Conditional logic
- Control flow

## How It Works

Reva does not use machine learning or an external AI API.

Instead, it checks the user's input against predefined rules.

```text
User Input
    ↓
Check predefined rules
    ↓
Find matching condition
    ↓
Generate response
    ↓
Ask for another input
    ↓
Continue until exit command
